# Управление vLLM TPU из Minecraft — Windows

В моде **0.2.0** появилось окно целей: **F7**. Оно позволяет ввести цель, выбрать до 30 шагов, включить PNG и смотреть статус. Модель работает в Colab; Windows-контроллер связывает её с игрой. Его и туннель нужно запустить один раз для текущего мира.

В **0.2.1** добавлена отдельная команда прыжков на месте. Обнови JAR и файлы Windows-контроллера, чтобы модель увидела её среди доступных действий.

![Окно целей в Minecraft](media/model-window.png)

## 1. Обнови мод и контроллер

1. Закрой Minecraft. Скачай [minebridge-0.2.1.jar](https://github.com/Cloudeah/minebridge/blob/main/releases/minebridge-0.2.1.jar) кнопкой **Download raw file**.
2. Удали предыдущий JAR minebridge из папки `mods` и положи новый. Две версии одновременно устанавливать нельзя.
3. Скачай свежий **Code → Download ZIP** [репозитория](https://github.com/Cloudeah/minebridge) и обнови файлы в `C:\minebridge`. Сохрани свои локальные настройки `.minebridge-colab.json`.
4. Нужны Minecraft **26.1.2**, NeoForge **26.1.2.97**, Java **25** и Python **3.12**. Если окружение Python ещё не готово:

```powershell
cd C:\minebridge
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r python\requirements.txt
```

## 2. Запусти мир и модель

1. Открой одиночный мир. Нажми **F3+P**, чтобы игра продолжала работать при переключении между окнами. Закрой меню Escape.
2. Скачай обновлённый [блокнот](https://github.com/Cloudeah/minebridge/blob/main/examples/vllm_tpu_colab.ipynb) и загрузи в Colab через **Файл → Загрузить блокнот**.
3. Выбери **TPU v5e-1** и выполни шаги **1–4** блокнота. Должен появиться тестовый JSON. В шаге 2 оставь `JAX_PLATFORMS: "tpu,cpu"`.

Подробности установки, ngrok и диагностики — в [основном гайде vLLM TPU](VLLM_TPU_COLAB_RU.md).

## 3. Подключи Windows-контроллер

В первом PowerShell:

```powershell
cd C:\minebridge
.\.venv\Scripts\python.exe examples\vllm_colab.py --config "$env:APPDATA\.minecraft\config\minebridge\bridge-owner.json" --interactive
```

Если launcher использует другую игровую папку, подставь её путь к `bridge-owner.json`. В этом режиме цели задаются из игры; запуск цели после разрешения владельца выполняет действия.

Во втором PowerShell запусти ранее настроенный ngrok:

```powershell
C:\ngrok\ngrok.exe http http://127.0.0.1:8766
```

В шаге **5** блокнота введи HTTPS-адрес ngrok и значение `token` из `C:\minebridge\.minebridge-colab.json`. Этот токен вводится в скрытое поле и не передаётся модели.

## 4. Оставь блокнот готовым к целям из игры

В шаге **6** блокнота установи:

```python
DECISIONS = 30
KEEP_READY_BETWEEN_GOALS = True
```

Запусти ячейку. Она ждёт задания и принимает до **30 решений суммарно**, включая разные цели. После исчерпания лимита или десяти минут без заданий запусти шаг 6 снова. Сервер модели и Windows-контроллер перезапускать не требуется.

## 5. Задай цель в Minecraft

1. Нажми **F7**. Внизу должно быть «Windows-контроллер подключён».
2. Нажми **«Разрешить · F8»** или клавишу F8.
3. Для первой проверки введи: **«Ничего не выполняй. Выбери wait и напиши, что соединение работает»**. Поставь **1** шаг, выключи PNG и нажми **«Запустить цель»**.
4. Окно закроется, игра продолжит работать. Нажми F7 снова, чтобы увидеть статус и пояснение модели.
5. После проверки задай короткую цель, например **«Посмотри на точку на три блока восточнее текущей позиции игрока»**, один шаг. Запусти и проверь результат.

Статусы показывают ожидание контроллера, ожидание модели, выполнение, остановку или ошибку. Исчерпание шагов означает конец короткой последовательности; оно не объявляет всю цель достигнутой. Для следующей цели введи новый текст в том же окне.

Ручные клавиши, кнопки мыши, изменение взгляда и обычное игровое меню прерывают текущую цель. Запоздалое решение после ручного вмешательства, F9 или новой цели отклоняется модом. Ввод текста и кнопки самого окна F7 не считаются вмешательством.

## 6. Включи зрение

1. Выполни шаг **7** блокнота — остановку сервера.
2. В шаге **3** установи `ENABLE_VISION = True` и повтори шаги **3–5**.
3. Вновь запусти шаг **6** с параметрами из пункта 4 этого гайда.
4. В игровом окне включи **«Передавать PNG»**. Флаг `--vision` у контроллера в режиме `--interactive` не нужен: настройка берётся из окна каждой цели.

Передаётся кадр **320×180**. Если зрение включено в игре, но выключено в сервере, окно покажет ошибку; действие выполняться не будет.

## 7. Останови и восстанови подключение

- **F9** или кнопка **«Остановить»** останавливают цель и игровые задачи. Перед следующим запуском снова нужен F8.
- Для новой цели оставь Windows-контроллер и ngrok работающими. Проверь, что ячейка 6 Colab ещё принимает задания.
- При выходе из мира или смене измерения сессия моста закрывается. После входа перезапусти Windows-контроллер; повтори шаг 5 блокнота, если изменились адрес или токен, и шаг 6, если ячейка закончилась.
- Для полного завершения: F9, Ctrl+C в терминалах Windows, шаг 7 блокнота и отключение среды Colab.

Клавиши можно переназначить в настройках Minecraft. Внешние multiplayer-серверы остаются в режиме наблюдения; окно целей не добавляет управляемые действия в такую сессию.

## 8. Если модель вернула неправильный JSON

`Expecting ',' delimiter` означает синтаксическую ошибку в ответе модели. Например, JSON не допускает `"x": 10.5 + 3`: модель должна сначала вычислить число и записать `"x": 13.5`. Для диагноза нужен сам ответ, поэтому обновлённый адаптер выводит его в Colab. Он делает одну повторную генерацию с уточнением формата и проверяет её; неверное решение не становится игровой задачей.

Чтобы обновить адаптер в уже работающем Colab:

1. Нажми F9 в игре и останови выполняющуюся ячейку **6** кнопкой ■. Сервер модели, Windows-контроллер и ngrok оставь работающими.
2. Скачай свежий [vllm_tpu_colab.ipynb](https://github.com/Cloudeah/minebridge/blob/main/examples/vllm_tpu_colab.ipynb) кнопкой **Download raw file**.
3. В текущем Colab добавь новую кодовую ячейку и выполни код ниже. В появившемся окне выбери скачанный notebook. Код загрузит только обновлённый адаптер из шага **4**, сохранив работающую модель и соединение. Затем появится тестовый JSON.

```python
from google.colab import files
import json

uploaded = files.upload()
notebook = json.loads(next(iter(uploaded.values())))
adapter = next("".join(cell["source"]) for cell in notebook["cells"]
               if cell["cell_type"] == "code"
               and "def infer_decision(payload):" in "".join(cell["source"]))
exec(adapter, globals())
```

4. Повтори ячейку **6** с `DECISIONS = 30` и `KEEP_READY_BETWEEN_GOALS = True`. В игре нажми F8 и запусти цель снова, с одним шагом и без PNG. Обновлять JAR или переустанавливать пакеты для этой правки не требуется.

Если обе попытки не прошли проверку, сохрани вывод «Ответ модели» из Colab. Последний ответ также доступен в новой ячейке через `print(LAST_MODEL_REPLY)`. Повторы генерации используют то же наблюдение, общий бюджет времени и проверку длины контекста; задача передаётся моду только после успешной проверки. F9 и ручное вмешательство по-прежнему отменяют цель и отклоняют запоздалое решение.

## 9. Прыгни десять раз

Нужны JAR **0.2.1** и обновлённый `examples/ollama_colab.py`, который используется также контроллером vLLM. После обновления файлов перезапусти Minecraft и Windows-контроллер. Адаптер текущего Colab можно обновить по пункту 8; модель переустанавливать не требуется. Если `allowedActions` в конфигурации владельца непустой, добавь в него `move.jump` при закрытом мире.

В окне F7 поставь **один шаг**, выключи PNG и задай **«Прыгни десять раз на месте»**. Ожидаемое решение:

```json
{"action":"move.jump","parameters":{"count":10},"reason":"Прыгнуть десять раз на месте"}
```

Это одна задача, внутри которой мод выполняет десять прыжков через обычную клавишу прыжка. Следующий прыжок начинается после серверного подтверждения предыдущего приземления. Итог содержит `completed: 10` и `confirmed_changes.jumps: 10`. Игрок должен стоять на земле, вне воды/лавы, полёта и транспорта. Если отрыв не подтверждён, прыжок не засчитывается; F9 прекращает новые прыжки, уже начатый заканчивается естественным приземлением.

`count` допускает 1–30. Для длинной серии увеличь лимит Windows-контроллера, например добавь `--task-ticks 800`; стандартные 200 тиков проверены для десяти обычных прыжков. `item.use` использует предмет в руке и прыжки не выполняет. Если нужная команда не объявлена модом, модель получает инструкцию выбрать `wait` и объяснить ограничение.
