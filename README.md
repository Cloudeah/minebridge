# Minecraft AI Bridge

Мод для **Minecraft 26.1.2 / NeoForge 26.1.2.97**, связывающий существующего игрока с внешним контроллером через WebSocket. Внешний ИИ выбирает цели; мост выполняет их по игровым тикам и возвращает фактический результат.

Первая реализация спецификации из `Minecraft_AI_Bridge.docx`. Поддержка ограничена описанными механиками; наличие API не означает совместимость с любой сборкой. Результаты проверок: [docs/VALIDATION.md](docs/VALIDATION.md).

## Скачать готовый мод

[Скачать minebridge-0.2.1.jar](https://github.com/Cloudeah/minebridge/blob/main/releases/minebridge-0.2.1.jar) кнопкой **Download raw file**. Это проверенная сборка из репозитория; файл и [SHA-256](releases/minebridge-0.2.1.jar.sha256) находятся в `releases/`.

Нужны **Minecraft 26.1.2**, **NeoForge 26.1.2.97** и **Java 25**. Скопируйте JAR в папку `mods` клиента, откройте одиночный мир и используйте F8 для разрешения управления, F9 для остановки. Настройка внешнего контроллера описана ниже.

## Подключить модель через Ollama в Google Colab

[Пошаговый гайд для Windows](docs/OLLAMA_COLAB_RU.md) включает готовый [Colab notebook](examples/ollama_colab.ipynb), локальный контроллер, HTTPS-подключение, первый запуск без выполнения, управление и RGB-зрение. Minecraft и Python-контроллер работают на компьютере; Ollama и модель — в Colab.

Этот вариант использует GPU.

## Управление нейронкой из игры

В версии **0.2.0** клавиша **F7** открывает окно целей: текст, число шагов, PNG-зрение, запуск, остановка и статус. [Гайд для Windows](docs/INGAME_VLLM_RU.md) показывает подключение через `examples/vllm_colab.py --interactive` и настройку блокнота для нескольких целей подряд. F8 разрешает управление, F9 останавливает его. Компактный профиль наблюдений рассчитан на небольшой контекст модели; мод отклоняет запоздалые действия после ручного вмешательства.

В **0.2.1** добавлено `move.jump` с `count: 1..30`: прыжки на месте с подтверждением каждого отрыва и приземления сервером. Цель «Прыгни десять раз» выполняется одной задачей с `count: 10`; в окне достаточно одного шага. Обновите также Windows-контроллер: он передаёт модели новую команду и объясняет, что `item.use` использует предмет, а неподдержанная цель требует `wait`.

## Сборка и запуск

Нужны JDK 25 и доступ к Maven Central, Maven NeoForge и официальным ресурсам Minecraft. Gradle 9.2.1 включён; дистрибутив проверяется по SHA-256.

```bash
./gradlew :core:test :mod:build
./gradlew :mod:runClient
```

Мод: `mod/build/libs/minebridge-0.2.1.jar`. Установите его в `mods` клиента с указанной версией NeoForge. Java-WebSocket вложен в JAR; Gson предоставляется Minecraft.

В облачной среде: `python scripts/dev.py :core:test :mod:build`. Помощник находит JDK 25 в `/workspace/toolchains`, использует штатный прокси и системное хранилище доверенных сертификатов. Графическому клиенту нужен дисплей OpenGL; звуковое устройство не требуется.

1. Откройте одиночный мир. Мод создаст `config/minebridge/bridge-owner.json` с случайным токеном и портом 8765. В dev-запуске файл находится под `mod/run/`.
2. Подключитесь к `ws://127.0.0.1:8765/bridge`, выполните `session.hello` и `session.authenticate`.
3. **F8** разрешает управление. **F9** — независимая аварийная остановка. Клавиши можно переназначить.
4. После остановки снова нужен F8. Ручные клавиши, кнопки мыши и изменение взгляда приостанавливают текущую задачу; игровое меню также ставит её на паузу.

Токен не печатается в журнал и capabilities. Права файла на POSIX — `0600`; не добавляйте его в Git. Мост слушает только loopback, отклоняет браузерный Origin. Для удалённого ИИ используйте SSH-туннель или аутентифицированный шлюз WSS.

## Внешний клиент

Python 3.11+:

```bash
python -m venv .venv
.venv/bin/pip install -r python/requirements.txt
.venv/bin/python examples/client.py snapshot
.venv/bin/python examples/client.py craft-plan minecraft:stick 4
.venv/bin/python examples/client.py move 10 64 20
.venv/bin/python examples/client.py vision scene
.venv/bin/python examples/client.py stop
```

`vision scene` сохраняет PNG, JSON и depth float32 little-endian. Захват мира выполняется до рук и HUD. Для обычного запуска передайте `--config /путь/к/config/minebridge/bridge-owner.json`; токен читается из файла.

```python
from minebridge_client import BridgeClient

async with BridgeClient.from_owner_file("config/minebridge/bridge-owner.json") as bridge:
    state = await bridge.request("observe.snapshot")
    accepted = await bridge.submit("move.to", {
        "target": {"x": 10, "y": 64, "z": 20}, "tolerance": 0.7
    }, timeout_ticks=1200, max_actions=10000)
    result = await bridge.wait_task(accepted["task_id"])
```

## Поддержанные механики

| Область | Реализация и ограничения |
| --- | --- |
| Сессия | Один игрок и контроллер; версия, токен, capabilities, ping и resume |
| Наблюдение | Игрок, инвентарь, открытое меню, видимые сущности/блоки; revision, время, тик, подписки |
| Видимость | Лучи движка; закрытые контейнеры не читаются. Телеметрия включается владельцем |
| Задачи | accepted → queued → running / paused; succeeded / failed / cancelled; приоритет, зависимости, срок и бюджет |
| Маршруты | Ограниченный A*, ходьба, бег, прыжок на один блок; перепланирование и обнаружение застревания |
| Бой | Ближняя атака, дистанция, cooldown, опциональное преследование; атака игроков отключена |
| Блоки | Штатная добыча с проверкой инструмента; block item из hotbar, видимая опора, проверка свойств |
| Инвентарь | Осмотр, hotbar, точный перенос количества между слотами текущего меню, экипировка через соответствующий слот |
| Карта/память | Наблюдённые блоки, происхождение и время, world/dimension, пометки ИИ, сохранение и устаревание |
| Крафт | Цепочки shaped/shapeless, альтернативы ингредиентов/рецептов, выходы, остатки, станции, серверное подтверждение |
| Строительство | Поворот, материалы/конфликты, подход, размещение, частичный результат, финальная проверка всех блоков |
| Зрение | PNG + нативная глубина одного framebuffer, камера, связанный снимок, объекты, crop и поток |
| Разрыв связи | Освобождение управления, пауза задач, история и результаты; явное возобновление |

Для крафта 3×3 должен быть открыт доступный верстак. Сырьё не добывается автоматически. Каталог берётся со встроенного сервера; динамические, компонентно-зависимые и машинные рецепты не поддерживаются. `count` — целевое количество предмета в инвентаре, а не безусловное дополнительное производство.

Строительство сохраняет существующие блоки. Для замены нужна отдельная `block.break`; `replace=true` отклоняется. Материал должен быть в hotbar. Не каждое сочетание свойств достижимо штатным размещением: неподтверждённая ориентация возвращает ошибку с фактическим состоянием, без автоматического удаления блока. Чертёж ограничен 4096 блоками.

Взаимодействия подтверждают открытие меню или изменение состояния блока; непроверяемые эффекты дают `interaction_unconfirmed`. Не реализованы компаньон, плавание/полёт, дальний бой, автоматические жидкости/энергия/машины, произвольные интерфейсы модов и плотная карта ID пикселей. Они не объявляются в capabilities. Маршруты не загружают чанки и не изменяют мир для прохода.

## Настройки владельца

В `bridge-owner.json`: `port`, `radius` (1–24), `telemetry` (false по умолчанию), `allowedActions` (пустой список разрешает поддержанные действия), `areas`. Пример области:

```json
{"dimension":"minecraft:overworld","minX":-32,"minY":0,"minZ":-32,"maxX":32,"maxY":128,"maxZ":32}
```

Области проверяются для движения, боя, блоков и каждой позиции чертежа. Меняйте файл при закрытом мире. На внешнем сервере клиентский мост предоставляет наблюдение без управляемых действий.

На выделенном сервере администратор выполняет `/minebridge observe <player>` для структурной сессии и `/minebridge stop` для её закрытия. Зрение и действия в этом адаптере недоступны. Токен в серверном файле владельца; доступ локальный. Выбор игрока повторяется после перезапуска.
